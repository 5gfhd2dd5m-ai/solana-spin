# Solana India — static site

Видео-референс: загруженный пользователем MP4.
Сайт сделан как самостоятельная responsive landing page:
- Hindi/Devanagari typography
- Solana-style orange/green palette
- Animated spin wheel
- Responsive mobile layout
- No backend required for the demo

## Запуск
Откройте `index.html` в браузере или разместите все три файла на любом static hosting.

## Важно
Это визуальный демо-прототип. Реальный Solana wallet connect, on-chain verification и выплаты не подключены.
